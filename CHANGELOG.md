## 2026-09-28

### Added
- Initial publish of Playlist Bench — M3U Editor.
- Channel/group editing, drag-drop reordering, bulk find/replace, bulk group assignment, bulk stream URL http/https scheme fix, auto-clean names.
- GitHub-based logo matching with manual picks, hover-zoom preview, and a "needs review" filter.
- Multi-source XMLTV EPG matching with per-source fetch and combined now/next.
- Loading playlists from a local file, a URL, or an Xtream Codes portal.
- Integrated logo resizer (batch resize/pad/background/format, pull from playlist).
- Per-playlist settings memory (GitHub URL, Xtream credentials, load URL, resize defaults), stored per filename.
- Light/dark theme toggle.
- English/Portuguese language toggle.
- Built-in help modal.
- `index.html` redirect for GitHub Pages hosting.
